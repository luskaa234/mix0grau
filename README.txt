MIX0GRAU V4 — PC + CELULAR

IMPORTANTE: o erro Unexpected end of JSON input costuma ocorrer quando o site é aberto via arquivo ou executado com py -m http.server 3000. Este projeto usa API e banco SQLite, então rode SERVER.PY.

Windows (Prompt de Comando):
1. Extraia todos os arquivos.
2. Abra o Prompt de Comando nesta pasta.
3. Execute: set MIX0GRAU_ADMIN_PIN=EscolhaUmPinForte
4. Execute: py server.py
5. Acesse http://localhost:3000
6. Painel: http://localhost:3000/admin.html

No PowerShell, use: $env:MIX0GRAU_ADMIN_PIN="EscolhaUmPinForte"

ATENÇÃO: o banco de dados será criado na primeira execução. Guarde o arquivo mix0grau.db após começar a receber pedidos.

Cadastro atual é demonstrativo e não verifica a posse do WhatsApp. Não publique na internet sem autenticação verificada, HTTPS e revisão de segurança.
Os copos seguem desabilitados até cadastrar preços. As fotos são ilustrações SVG.
